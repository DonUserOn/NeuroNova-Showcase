# NeuroNova Project Showcase

## One-Line Summary

NeuroNova is an AI study assistant and learning platform that turns tutoring conversations into saved notes, practice, review, planning, and progress tracking.

## Short Pitch

NeuroNova helps students move beyond one-off chatbot answers. It creates a connected study loop where students can ask questions, save explanations, practice actively, review weak topics, and track their growth over time.

## Main Value Proposition

Students often get useful AI explanations but lose them inside chat history. NeuroNova organizes those explanations into a learning system with study tools, reminders, progress dashboards, personalization, and review workflows.

## Core Workflow

**Ask -> Save -> Practice -> Review -> Track Progress**

## Key Features

- AI Tutor with student-friendly explanations
- Notebook for saved study material
- Flashcards and quiz workflows
- Study Planner and Daily Missions
- Focus Session support
- Review Queue and weak-topic practice
- Upload-to-study workflow for supported documents
- Progress dashboard and Weekly Report
- Personalization settings for learning style and study goals

## Technical Highlights

- Built as a modular Python/Streamlit MVP
- Designed with separate learning, planning, review, reporting, and personalization modules
- Uses an AI routing/fallback concept for resilient behavior
- Includes public-safe deployment, privacy, and upload validation practices
- Prepared for future migration to a more scalable full-stack architecture
