# Privacy And Security

## Public Showcase Scope

This repository is a public showcase package. It does not include the private NeuroNova source code, `.env` files, API keys, database files, saved user data, private prompts, or internal development reports.

## Demo Data Only

The public demo should use sample data only. Do not use real private student records, private emails, private notes, or sensitive uploaded documents in screenshots or recordings.

## Sensitive Documents

Users should not upload sensitive private documents to the MVP/prototype. Examples include IDs, medical documents, financial documents, school records, private exams, or confidential files.

## API Keys

API keys are handled through deployment environment variables. They should never be committed to GitHub or included in showcase materials.

## Upload Validation

NeuroNova includes upload validation in the MVP, including limited file types, file size limits, content checks, safe filenames, and friendly student-facing errors. Antivirus scanning should be added before production use.

## Private Main Repository

The main source-code repository is private for security, development control, and to avoid exposing internal implementation details before the project is production-ready.

## Prototype Notice

NeuroNova v1.0 is an MVP/prototype. It should be reviewed and upgraded before handling real sensitive student data in production.
