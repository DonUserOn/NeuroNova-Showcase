# NeuroNova Demo Script

## 30-Second Demo Script

"This is NeuroNova, an AI Study Assistant & Learning Platform. Instead of only answering questions like a normal chatbot, NeuroNova helps students follow a complete study loop: ask, save, practice, review, and track progress. I can ask AI Tutor for an explanation, save it to Notebook, create review material, add a study task, and then see my progress in dashboards and weekly reports."

## 60-Second Demo Script

"NeuroNova is my AI-powered study platform. The main idea is to turn AI help into an organized learning workflow. On the Home dashboard, students can jump into AI Tutor, Notebook, Study Planner, Review Queue, and Progress. In AI Tutor, a student asks a question and gets a clear explanation. The useful answer can be saved, reused for flashcards or quizzes, added to a planner, and reviewed later. NeuroNova also includes study reminders, personalization settings, upload support for limited safe file types, and progress reports. This public repository is only a showcase; the main source-code repo is private for security and development control."

## Step-By-Step Screen Recording Flow

1. Home dashboard
   - Say: "This is the student command center, where the main study workflows are one click away."
   - Show Quick Actions, Today's Mission, Progress Summary, and Study Reminders.

2. AI Tutor
   - Say: "AI Tutor gives student-friendly explanations and can be used as the first step in the study loop."
   - Ask a simple demo question using non-private sample data.

3. Notebook
   - Say: "Useful explanations can be saved so they do not disappear into chat history."
   - Show a demo saved note.

4. Study Tools
   - Say: "From saved material, the student can practice with flashcards, quizzes, review tasks, and planner items."
   - Show Study Canvas, Review Queue, or Study Planner.

5. Progress
   - Say: "NeuroNova tracks activity so the student can see learning momentum."
   - Show Progress and Weekly Report.

6. Settings
   - Say: "Students can personalize learning preferences, explanation style, and study behavior."
   - Show settings without exposing private account data.

## Demo Safety Tips

- Use demo data only.
- Do not show private email addresses.
- Do not show API keys.
- Do not open `.env` files.
- Do not upload real private documents.
- Use sample notes, sample quiz topics, and fake study material.
